# Saeidbakhsh Typography Manager

![Saeidbakhsh Typography Manager Screenshot](https://ps.w.org/saeidbakhsh-typography-manager/assets/screenshot-1.png?rev=3690637)

A powerful and flexible typography management plugin for WordPress.

Saeidbakhsh Typography Manager gives website owners and developers full control over their website typography without editing theme files or writing custom CSS.

Manage fonts, sizes, spacing, colors, and text direction for HTML elements, WordPress blocks, and WooCommerce components from:

**Appearance → Typography Manager**

## Features

- Manage typography for HTML, WordPress, and WooCommerce elements
- Support system fonts, WordPress Font Library fonts, and HTTPS font URLs
- Customize:
  - Font family
  - Font size
  - Font weight
  - Line height
  - Letter spacing
  - Colors
  - Text direction
- Responsive typography settings
- Custom CSS selector support for advanced users
- Instant search for fonts and elements
- Edit multiple typography groups before saving
- CSS priority control for themes and page builders
- Generated CSS preview before applying changes
- Compatible with popular caching and optimization plugins

## WooCommerce Support

The plugin includes typography controls for common WooCommerce areas:

- Shop pages
- Product pages
- Cart
- Checkout
- Account pages

WooCommerce controls remain inactive when WooCommerce markup is not detected.

## Performance & Compatibility

Designed with performance and long-term maintenance in mind:

- Generates reusable CSS instead of processing every frontend request
- Works with caching plugins
- Uses WordPress native APIs
- No telemetry
- No background font downloads
- No external runtime dependencies

## Requirements

- WordPress 6.5+
- PHP 7.4+
